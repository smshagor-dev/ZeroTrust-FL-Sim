# ZeroTrust-FL-Sim Web Dashboard

Pixel-matched local operations dashboard for ZeroTrust-FL-Sim. It mirrors the project reference UI with a fixed dark sidebar/header shell, KPI cards, federated convergence charts, aggregation acceptance/rejection bars, CPU/GPU/memory telemetry, worker status, network topology, live logs, and attack/training controls.

## Run

```bash
npm install
npm run dev -- --port 8080
```

When the repository root orchestrator is running, the dashboard polls `/api/dashboard` every 1.5 seconds. The route reads `../tmp/orchestrator/dashboard-state.json` and worker registration health files generated by the existing Python/Go stack. If no live run exists, the page renders a deterministic preview so the complete layout is still visible.

The red **Stop Training** button writes `tmp/orchestrator/dashboard-command.json`; `scripts/run_master_training.py` consumes that command at a round boundary and exits cleanly, allowing the root process manager to terminate the remaining child processes.

## Build

```bash
npm run typecheck
npm run build
```

The frontend uses Next.js App Router and React without an external chart/UI package. The charts, topology, shield mark, and navigation icons are rendered with native SVG/CSS so the visual design does not depend on third-party assets.
